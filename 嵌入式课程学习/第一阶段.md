- 计算机的工作方式

  - 结构特点：CPU（寄存器）、内存（cpu 能直接访问。分为 ROM：掉电不易失、RAM：掉电易失）、外存    （cpu 不能直接访问。掉电不丢失）
  	![](img/day02-cpu存储器关系.png)
  - 速度特点：寄存器 > 内存 > 外存
  - 容量特点：寄存器 < 内存 < 外存

- **C 语言的本质是，操作内存**

	- 8 比特(bit) = 1 字节(byte，简写为 B)    比特是最小的数据单位

- **数据类型的本质是：大小和行为** ==> 在内存上划分多大的盒子来存储数据，其中是否需要特殊位（符号位）

- **指针的本质是 “存储内存地址的变量”**，其大小等于 CPU 的 **地址总线宽度**

	- 32 位 CPU：地址总线宽度 32 位 → 指针占 4 字节（能表示 `0 ~ 2³²-1` 的内存地址）；
	- 64 位 CPU：地址总线宽度 64 位 → 指针占 8 字节（能表示 `0 ~ 2⁶⁴-1` 的内存地址）；
	- 关键：指针大小 **与指向的类型无关**（`char*`/`int*`/`double*` 大小完全一致），只和 CPU 架构有关。

		| 二进制表示  | 数值       |
		| ----------- | ---------- |
		| 0x0000 0001 | 2^0^ = 1   |
		| 0x0000 0010 | 2^1^ = 2   |
		| 0x0000 0100 | 2^2^ = 4   |
		| 0x0000 1000 | 2^3^ = 8   |
		| 0x0001 0000 | 2^4^ = 16  |
		| 0x0010 0000 | 2^5^ = 32  |
		| 0x0100 0000 | 2^6^ = 64  |
		| 0x1000 0000 | 2^7^ = 128 |

		将 100 转换成二进制：100 = 64 + 32 + 4  —–>   0b0110 0100
		将 0b0000 1010 转换成十进制：0b0000 1010 = 0b0000 1000 + 0b0000 0010 = 8 + 2  ——> 10

	- **⼀ 位 ⼋ 进制对应三位 ⼆ 进制**     互相转换也可以用 8421 方法

	- **⼀ 位十六进制对应四位 ⼆ 进制**    互相转换也可以用 8421 方法

	- 其余方法：n 进制转二进制 ——辗转相除法   二进制转 n 进制 —— 按位 × 权重，再相加**

- 指针

	- 指针本质：

	- `数据类型 *(&变量名);`

		- & ：取出变量的地址 ，拿该盒子中最低的内存编号（首地址）
		- *：指针标志（表示地址）。
		- 数据类型：通过什么形式取出数据 -> *()

	- 指针定义：`数据类型 *变量名`

		- **定义一个专门用于存储变量地址的盒子**。使用该盒子之前，需要告知以什么形式取出该地址中数据

		- 指大小：与操作系统的地址总线相关。eg.  32位操作系统 -> 32根地址总线 -> 指针大小为4B

		- 行为：如何处理该内存中的数据

			1. 当作一个数据（普通指针）。eg.  char、long 、int
			2. 当作一个地址（多级指针）。eg.  char *、long * 、int *
			3. 当作一段代码（函数指针），存的是代码的入口。eg. int (\*p)(int a,int b);   ——>   返回值类型 (* 变量名)(形参列表)

		- 指针既可以像数组一样同下标访问（[]），也可以通过（*）

		- 

			```c
			#include <stdio.h>
			
			int fun(int a,int b){
			    return a + b;
			}
			
			int main(){
			
			    int arr[5] = {1,2,3,4,5};
			    int *p = arr;                   // 等价于 int *p = &arr;
			    int **pp = &p;                  // 二级指针，pp存储的是p的地址
			    int (*funP)(int,int) = fun; // 函数指针，funP存储的是fun的首地址
			
			    // 无论指针前面的数据类型是什么，指针大小都只和地址总线关
			    printf("%d %d %d\n\n",sizeof(p),sizeof(pp),sizeof(funP));     // 8 8 8  现在是64位操作系统 
			
			    // 二级指针
			    printf("%d %d %d\n",arr[0],*p,**pp);          // 1 1 1  数组第一个成员的数据
			    printf("%p %p %p\n",&arr[0],p,*pp);           // 数组第一个成员地址
			    printf("%p %p\n",&p,pp);                      // 指针p的地址
			    printf("%p\n\n",&pp);                         // 指针pp的地址
			
			    // 函数指针
			    printf("%d\n",funP(1,2));                   // 3 相当于 printf("%d",fun(1,2)); 
			    printf("%p %p\n",funP,fun);                 // fun的地址
			    printf("%p\n\n",&funP);                     // funP的地址
			
			    // 指针两种访问形式
			    printf("%d %d\n",*p,p[0]);                    // 1 1 
			
			    return 0;
			}
			// 现象
			/*
			8 8 8
			
			1 1 1
			975ffb80 975ffb80 975ffb80
			975ffb78 975ffb78
			975ffb70
			
			3
			163614a4 163614a4
			975ffb68
			
			1 1
			*/
			```

		- 变量名：存的谁的内存编号  （p中是arr的首地址）

		- \* 变量名：指代谁 （\*p是arr中第一个成员）

  - 指针常量（pointer to constant ）（重点是“常量”）：const int *p; 或者  int const *p;        指向的盒子中内容不能用这个变量修改（指向变量的值不能变）

  - 常量指针 （constant pointer ）（重点是“指针”）： int * const p;        指向的方向不能用这个变量修改（存的地址不能变）

  - const int * const p;    固定方向，固定数值（指向的地址内容 与 存的地址都不能）

  - 判断方法：

  	1. 去掉 数据类型
  	2. 看const修饰谁 谁就无法改变（可以使用其他变量获取其地址来改变内容）

       * @dest: Where to copy the string to
       * @src: Where to copy the string from

      char *strcpy(char *dest, const char *src)
      {
      	char *tmp = dest;
      
      	while ((*dest++ = *src++) != '\0')			// 先用完，在加加 *dest = *src; *dest != '\0'; *dest++;*src++
      		/* nothing */;

       * strncpy - Copy a length-limited, C-string
       * @dest: Where to copy the string to
       * @src: Where to copy the string from
       * @count: The maximum number of bytes to copy
       *
       * The result is not %NUL-terminated if the source exceeds
       * @count bytes.
       *
       * In the case where the length of @src is less than  that  of

       *
       */
      char *strncpy(char *dest, const char *src, size_t count)

      	char *tmp = dest;
      
      	while (count) {
      		if ((*tmp = *src) != 0)
      			src++;
      		tmp++;
      		count--;
      	}
      	return dest;
      }

- 上面的知识 ==》 单个盒子的大小和行为； 数据结构 ==》 盒子之间的关系

- 盒子之间的关系

	- 存储关系：
		- 顺序存储结构：数据存储在连续空间上，且每个数据之间的逻辑关系也映射到了内存中。
			如：a,b,c 内存中的存储顺序也应该为a,b,c
		- 链式存储结构：数据存储在分散的空间上，每个数据中应该包含下一个数据的地址。访问数据时，通过地址进行访问  一个链式的盒子 -> (数据域，指针域) -> (D,S) (数据域：有多个数据；指针域：指向多个位置)
		- 两种存储的组合应用：
			- 索引存储：索引表 + 数据文件 类似于查字典，通过索引表确定数据的存储在哪个范围。
			- 哈希存储：数据的存储地址 与 数据本身建立关（该关系自己定义—— 哈希函数）
				如：通过数据中的某些属性（如id），找到与地址的关系（id - 起始位置的id = 地址的偏移） 
	- 逻辑关系
		- 集合：数据之间没有任何关系（1 ：0）
			![](img/day013-集合.png)
		- 线性结构 ： 数据之间存在1对1的关系（1:1 —— 即最多一个前驱节点和一个后驱节点），如： 学生表（通过上一个学号，能知道当前学号的学生信息）
			![](img/day013-线性.png)
		- 树形结构：数据之间存在1对多的关系（1:n —— 即只有一个前驱和多个后驱），如：家谱（爷爷下面有很多人，包括父亲，父亲下面又有很多人）
			![](img/day013-树形.png)
		- 图形结构：数据之间存在多对多的关系（n:m —— 即任意链接，可以形成环），如：城市的火车线路（成都有到重庆、北京、上海…的火车线路，上海也有到成都、北京、重庆的线路）
			![](img/day013-图形.png)
	- 行为关系：增删改查

- 代码质量评估

	- 时间复杂度：执行一段操作，需要的时间
	- 空间复杂度：执行一段操作，需要的空间
	- 二者互相矛盾，时间快，空间就大；空间小，时间就慢

- **线性表**

	- 顺序表：静态顺序表、动态顺序表
		- 随机索引
		- 占用连续空间
		- 增删会移动元素
	- 链表
		- 不能随机索引
		- 空间动态分配（空间不够的时候，申请一个更大的空间，将原本的数据拷贝过去，然后释放原空间）
		- 增删不移动元素

- **[cmake的使用](https://www.runoob.com/cmake/cmake-tutorial.html)**

	- CMake：项目管理工具。当项目中有很多文件需要编译时，通过CMake进行快速的gcc编译

	- CMake的管理文件都叫做`CMakeLists.txt`

	- ```Cmake
		# CMakeLists.txt 用法
		# cmake的版本名
		cmake_minimum_required(VERSION 3.10)
		
		# 定义项目的名称叫 MyPorject 使用C++
		project(MyProject CXX)
		
		# 等价于 g++ main.cpp other_file.cpp -o MyExecutable
		add_executable(MyExecutable main.cpp other_file.cpp)
		
		# 创建一个叫MyLibrary的静态库 以及 源文件library.cpp; STATIC:静态
		# g++ -c library.cpp -o MyLibrary.o
		# ar rcs libMyLibrary.a MyLibrary.o
		add_library(MyLibrary STATIC library.cpp)
		
		# 创建一个叫MyLibrary的动态库 以及 源文件library.cpp; SHARED:静态
		# g++ -c library.cpp -o MyLibrary.o
		# g++ -shared MyLibrary.o -o libMyLibrary.so
		add_library(MyLibrary SHARED library.cpp)
		
		# 链接目标文件与其他库
		# g++ main.cpp -o MyExecutable -L -lMyLibrary 动态库
		target_link_libraries(MyExecutable MyLibrary)
		
		# 定义变量
		# 使用C++11
		# g++ -std=c++11 main.cpp ... 会使用C++11 编译代码
		set(CMAKE_CXX_STANDARD 11)
		set(CMAKE_CXX_COMPILER g++)		# 使用g++编译器
		
		# 添加头文件搜素路径
		# -I ./temp/include 
		# PROJECT_SOURCE_DIR 是内部变量，存的是项目中CMakeLists.txt的目录路径
		include_directories(${PROJECT_SOURCE_DIR}/include)
		
		# 给MyLibrary库指定头文件路径
		target_include_directories(MyLibrary
		    BEFORE                  # 把这个路径优先搜索（放在最前面）
		    SYSTEM                  # 当作系统头文件（不报警告）
		    PUBLIC                  # /temp/public 自己用 + 别人链接我时也能用
		        ${PROJECT_SOURCE_DIR}/public  # 公共头文件
		
		    PRIVATE                 # /temp/private只有我自己内部能用
		        ${PROJECT_SOURCE_DIR}/private # 内部头文件
		
		    INTERFACE               # /temp/interface我不用，但别人用我时必须能用
		        ${PROJECT_SOURCE_DIR}/interface
		)
		
		# 安装规则
		install(TARGETS MyLibrary MyExecutable
		        # 可执行文件安装路径 /bin
		        RUNTIME DESTINATION bin
		        
		        # 动态库 .so 安装路径 /lib
		        LIBRARY DESTINATION lib
		        
		        # 静态库 .a 安装路径 /lib/static
		        ARCHIVE DESTINATION lib/static
		        
		        # 头文件整体安装路径 /include
		        INCLUDES DESTINATION include
		        
		        # 私有头文件安装路径 /include/private
		        PRIVATE_HEADER DESTINATION include/private
		        
		        # 公共头文件安装路径 /include/public
		        PUBLIC_HEADER DESTINATION include/public
		)
		
		# 条件语句
		if(WIN32)
		  message("当前是 Windows 系统")		# 打印消息
		elseif(UNIX AND NOT APPLE)
		  message("当前是 Linux 系统")
		elseif(APPLE)
		  message("当前是 macOS 系统")
		else()
		  message("未知系统")
		endif()
		
		# 自定义命令
		# 编译后自动执行：复制文件 + 打印信息 + 自定义命令
		add_custom_command(
		    TARGET MyExecutable      # 绑定到哪个目标
		    POST_BUILD               # 时机：编译完成后执行
		                            # 可选：PRE_BUILD(编译前) / PRE_LINK(链接前) / POST_BUILD(编译后)
		    
		    # 第一条命令：复制动态库到可执行文件目录
		    COMMAND ${CMAKE_COMMAND} -E copy
		            ${CMAKE_SOURCE_DIR}/libMyLibrary.so
		            ${CMAKE_BINARY_DIR}/
		    
		    # 第二条命令：输出提示信息
		    COMMAND echo "可执行文件已生成，动态库复制完成！"
		    
		    # 工作目录（命令在哪个文件夹执行）
		    WORKING_DIRECTORY ${CMAKE_BINARY_DIR}
		    
		    # 依赖：只有依赖文件更新了，才执行此命令
		    DEPENDS ${CMAKE_SOURCE_DIR}/libMyLibrary.so
		    
		    # 注释：编译时会显示这句话
		    COMMENT "正在复制依赖库并执行后续操作..."
		    
		    # 重要：自动转义命令参数，保证跨平台兼容（必须加！）
		    VERBATIM
		)
		
		# 打印信息
		message("普通信息")			 # 默认级别	直接打印文字
		message(STATUS "...")		# 状态提示（最常用）	打印 -- 文字
		message(FATAL_ERROR "...")	# 致命错误（停止编译） 红色报错 + 停止
		message(WARNING "...")	    # 警告	黄色警告
		
		# 检查库和包
		# Boost：要找的库名字（固定写法）
		# REQUIRED：必须找到！找不到就直接报错停止
		# 找Boost之后，会生成一以下变量
		# 	Boost_INCLUDE_DIRS   # 头文件路径
		# 	Boost_LIBRARIES      # 所有要链接的库
		# 	Boost_FOUND          # 是否找到
		find_package(Boost REQUIRED)
		
		# 注意：
		target_link_libraries(MyExecutable Boost::Boost)
		# 等价于
		include_directories(${Boost_INCLUDE_DIRS})  # 自动加头文件
		target_link_libraries(MyExecutable ${Boost_LIBRARIES})  # 自动链接库
		
		# 开启调试信息 + 地址越界检查
		add_compile_options(-g -fsanitize=address)
		
		# 链接时也必须加上参数
		add_link_options(-fsanitize=address)
		
		# 进入lib目录下执行子CMakeLists.txt
		add_subdirectory(lib)
		
		# 自动让 CMake 监听文件变化（关键！）
		# 只要 .c / .h 变了，自动重新编译库
		target_sources(mylib
		    PRIVATE
		        source/dynamicSequentialList.c
		)
		
		# Cmake使用 跳转到新建的build目录下 构建CMake文件 在终端输入以下命令
		cmake ..
		# 生成可执行程序
		cmake --build .
		```

### 知识

- 栈
	- 存在栈底、栈顶（指向新元素）
	- 数据先进后出
	- 压栈 和 弹栈 必须满足先进后出
		- 压栈（添加）选择 头插法（简单） 或者 尾插法
		- 弹栈（删除）选择 头删法（简单） 或者 尾删法
	- 没有数据的时候，栈顶尽量指向栈底之下。数组（0为底，栈底指向-1）；链表（栈底为NULL）
	- 分类：
		- 注：低地址为栈底 —— 递增; 高地址为栈底 —— 递减； 满：栈顶指向元素本身（能直接通过栈顶指针读出数据）；空：栈顶指向当前元素的下一个（需要++ 或者 - - 才能读出数据）
		- 满递增栈
		- 满递减栈
		- 空递增栈
		- 空递减栈
- 队列（只允许在⼀端进⾏插⼊操作，在另⼀端进⾏删除操作的线性表  ）
	- 存在队尾（插入的一端为队尾）、队头（取出的一端为队头）
	- 数据是先进先出
	- 入队与出队的方法必须满足先进先出
		- 入队（添加）选择头插法 或者 尾插法（简单）
		- 出队（删除）选择尾删法 或者 头删法（简单）
	- 循环队列，队头指针往后移，队尾指针会跳到队头初始位置 （解决假溢出）
	- 数组队列，会出现“假溢出”（队头向队尾移到时，导致一部分空间没有被维护了）
	- 队列是移动队尾、队头这个两个指针；而顺序表是移动数据。
	- 队头：指向最旧的元素的前一个盒子
	- 队尾：指向最新的元素的盒子
	- 顺序队列判断满、空：
		- 牺牲一个空间，使 队尾 + 1 == 队头 —— 满；队头 == 队尾 —— 空
		- 定义一个标志，队尾操作对标志赋值1，队头操作对标志赋值0，队头 == 队尾 && 标志 == 0  =》 空；队头 == 队尾 && 标志 == 0  =》 满
	- 循环队列，经常使用取余进行边界判断
